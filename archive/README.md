# Historical Results

`results/benchmark_selection/` is a verbatim relocation of the former `SelectBenchmark/results/` tree. These files were produced before the unified protocol and are retained for provenance only.

Associated reports and notes are in `docs/archive/`.

Historical run directories are local, Git-ignored artifacts under `outputs/legacy/`.

`code/legacy_schema/` contains the retired single-layer `Concept` / `Relation`
implementation. It is source history only and is not part of the installed
`socialclaw` package.
