# WA30 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：搬运绿色对象并与自主载具协作，把它们送到匹配目标区
- Gold Schema：7 条
- 覆盖：9 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 四向移动主载具 | 主载具向上、下、左、右移动；障碍或禁区阻止位移。 |
| ACTION5 拾取相邻未绑定对象 | 该对象绑定到载具并移动到携带锚点。 |
| ACTION5 放下当前携带对象 | 解除绑定，对象留在当前携带锚点位置。 |
| 载具移动会同步移动其绑定对象 | 载具和对象保持固定相对位置作为一个组合移动；组合碰撞会阻止该步。 |
| 自主载具每回合寻路到未分配对象再送往目标 | 空载自主载具选择未分配对象，载物后选择对应目标区，并沿可通行最短路移动一步。 |
| 不同自主载具类型使用各自目标集合 | 它只把对象送到该类型允许的目标区；其他目标区不算完成。 |
| 全部绿色对象在规定目标区且不再被携带时过关 | 每个对象都位于其目标集合中的某一区域，且所有绑定关系已解除时进入下一关。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
