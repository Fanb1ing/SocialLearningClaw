# G50T Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：记录路径并生成延迟重放分身，协作到达阶段终点
- Gold Schema：7 条
- 覆盖：7 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 沿可通行轨道移动角色 | 角色向上、下、左、右移动并记录该方向；墙或断路阻止位移。 |
| 自主单位每回合顺时针寻找首个可走方向 | 自主单位从当前朝向起最多右转四次，沿首个可通行方向前进一步。 |
| ACTION5 逐步倒放本阶段玩家路径 | 玩家每次沿最后一步的反方向回退，直到起点。 |
| 完整倒放后留下按记录延迟重放的分身 | 当前位置生成分身；它按原动作序列和设定延迟逐步重放。 |
| 完成倒放会推进到下一阶段目标 | 玩家切换到下一起点/终点关系，已有分身继续执行。 |
| 周期左移的边界吞没关键对象会失败 | 场景边界左移；关键角色/目标越出可用区域时 GAME_OVER。 |
| 玩家到达当前终点并完成全部阶段时过关 | 中间阶段允许封存路径；全部阶段完成后进入下一关。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
