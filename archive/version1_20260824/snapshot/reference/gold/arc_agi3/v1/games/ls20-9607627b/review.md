# LS20 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：在迷宫中修改携带物的形状、颜色和朝向，逐个匹配目标
- Gold Schema：7 条
- 覆盖：7 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 在迷宫网格中移动角色 | 角色向上、下、左、右移动一格；墙和不匹配目标阻挡移动。 |
| 三类修改格分别循环形状、颜色和旋转 | 当前携带物仅改变该修改格负责的一个属性，其余属性保持不变。 |
| 目标要求形状、颜色、旋转三属性完全匹配 | 三属性全部相同则目标被清除；任一属性不同则目标仍是阻挡。 |
| 时间拾取物补充动作预算 | 拾取物消失，剩余步数增加到关卡规定值以内。 |
| 移动危险物或陷阱会消耗生命并重置本关 | 生命减一并恢复关卡初始状态；生命耗尽时 GAME_OVER。 |
| 全部属性目标被清除时过关 | 关卡中不再存在未满足目标时进入下一关。 |
| 后续关卡的可见区域随角色位置变化 | 角色附近信息可见，远处被遮挡；遮挡不改变底层碰撞规则。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
