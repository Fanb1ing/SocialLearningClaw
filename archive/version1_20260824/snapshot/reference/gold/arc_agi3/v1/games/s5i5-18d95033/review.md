# S5I5 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：按颜色成组旋转和伸缩线段，使所有端点覆盖目标
- Gold Schema：6 条
- 覆盖：8 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION6 点击颜色按钮旋转该色全部线段 | 该颜色的每条线段绕其锚点旋转 90°；子部件随父部件递归变换。 |
| ACTION6 点击条形控件两侧缩短或延长关联线段 | 关联线段长度减少/增加一个单位，依朝向保持锚点并移动其子部件。 |
| 父线段变换递归携带所有子部件 | 所有直接和间接子部件保持相对连接关系同步变换。 |
| 变换导致线段互撞时整次操作回滚 | 所有受影响线段和子部件恢复到操作前的位置、朝向与长度。 |
| 每个目标点都被端点对象精确覆盖时过关 | 所有目标点坐标都有端点对象位于同一坐标时进入下一关。 |
| 有效点击耗尽步数时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
