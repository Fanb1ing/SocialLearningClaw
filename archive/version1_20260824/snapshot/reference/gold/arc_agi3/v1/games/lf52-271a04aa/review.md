# LF52 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：选择同类物体并按可用方向跳跃消除，清空目标集合
- Gold Schema：8 条
- 覆盖：10 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 推动可移动棋盘部件并滚动视野 | 同类可动部件按上、下、左、右移动；相机/棋盘在特定关卡同步平移。 |
| ACTION6 点击对象显示其可用跳跃方向 | 对象成为当前选择；只有“相邻处有可越过对象且再下一格为空/目标格”的方向显示为可用。 |
| 点击方向标记使选中对象跨越中间对象 | 对象移动到方向两倍距离的落点，中间的匹配对象被消除。 |
| 同类型落点对象可被合并消除 | 中点对象消失，移动对象到达落点；不同类型接触只播放反馈而不按同类消除。 |
| 特定落点会触发平台移动或相机位移 | 对应棋盘整体或平台按固定方向平移，从而开放后续跳跃。 |
| 清除规定的全部目标对象时过关 | 剩余普通目标对象达到关卡要求的终止数量（通常只剩最后一个）时进入下一关。 |
| ACTION7 恢复上一内部快照 | 恢复棋盘对象、选择和视野位置。 |
| 不同关卡共享分段动作上限 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
