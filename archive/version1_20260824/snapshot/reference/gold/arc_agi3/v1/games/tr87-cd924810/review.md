## 摘要

- 核心任务：根据上方示例翻译规则，调整下方输出序列使其成为输入的正确翻译
- Gold Schema：7 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 分隔符两侧的序列定义翻译规则 | 每对示例把左侧连续符号序列映射到右侧连续符号序列；符号的随机朝向不改变其类别。 |
| ACTION3/4 在可编辑符号或规则侧之间循环选择 | 选择标记向前/向后循环；普通关选择下方输出符号，规则编辑关可选择示例任一侧序列。 |
| ACTION1/2 循环当前选中符号的类别 | 符号类别按固定字典向前/向后循环；选中规则序列时整段各符号同步循环。 |
| 输入序列按示例规则从左到右分段翻译 | 从输入当前位置寻找可匹配的规则左侧，追加其右侧并继续，直到完整消耗输入。 |
| 树翻译关会把规则输出继续作为另一规则输入 | 第一次翻译产生的每个符号序列还需找到下一条规则并再次翻译。 |
| 双重翻译关要求通过中间规则链得到最终输出 | 规则可先经连接关系扩展，再用其输出匹配另一规则左侧并得到最终右侧。 |
| 候选输出等于完整翻译结果时过关 | 输入被规则完整分解且候选输出逐项等于推导输出时进入下一关。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
