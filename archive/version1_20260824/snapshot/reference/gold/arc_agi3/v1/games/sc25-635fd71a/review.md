# SC25 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：移动角色并在 3×3 面板输入法术图案，解除障碍后到达出口
- Gold Schema：9 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 按角色尺寸四向移动 | 角色向上、下、左、右移动；大尺寸角色先尝试整步，受阻时可尝试半步。 |
| ACTION6 点击法术图标选择待输入法术 | 对应法术成为当前参考；再次点击同一图标会演示其 3×3 图案。 |
| 点击 3×3 槽位切换布尔图案 | 该槽开/关翻转；当前九格与某个已解锁法术模板完全相等时自动施法。 |
| 传送法术把角色与循环目标交换/传送 | 角色移动到当前传送目标位置，并把目标端状态按循环顺序推进。 |
| 缩放法术在尺寸 1 和 2 间切换 | 角色缩小或放大；放大时寻找不碰撞的邻近偏移，完全无空间则保持原尺寸。 |
| 攻击法术沿当前朝向发射直线投射物 | 投射物前进到首个阻挡；命中特定可破坏物时将其及关联障碍移除。 |
| 时间拾取物降低已用动作数 | 拾取物消失，动作计数减少但不低于零。 |
| 角色进入出口时过关 | 角色补齐到出口中心后进入下一关。 |
| 移动、面板编辑和施法共享动作预算 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
