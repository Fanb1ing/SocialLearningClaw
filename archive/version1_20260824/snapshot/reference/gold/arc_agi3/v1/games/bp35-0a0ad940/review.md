# BP35 Gold Schema v1 — 人工审核稿

## 摘要

- 核心任务：在可翻转重力的平台空间中到达宝石/出口
- Gold Schema：7 条
- 覆盖：9 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION3/4 分别向左/右尝试移动 | 角色朝相应方向走一格；实体阻挡时原地播放碰撞反馈。 |
| 每次横向移动后沿当前重力方向坠落 | 角色持续移动到当前重力方向上的首个支撑面；镜头跟随最终高度。 |
| 点击重力装置会反转重力 | 重力方向上下反转，装置消失，角色沿新方向坠落。 |
| 点击机关会切换同组平台状态 | 同标识对象在其状态序列间切换，可能生成/移除相邻支撑，并立即重新结算坠落。 |
| 落到尖刺会失败 | 角色播放受击过程后进入 GAME_OVER。 |
| 接触宝石或出口即完成关卡 | 当前关完成；最终关满足时 WIN。 |
| ACTION7 撤销最近一次世界操作 | 恢复角色、重力与机关状态到上一快照。 |

- 是否有规则抽象过粗或应当拆分；
