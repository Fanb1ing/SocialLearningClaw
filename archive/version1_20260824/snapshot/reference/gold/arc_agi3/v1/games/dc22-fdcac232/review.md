# DC22 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：操纵角色与起重机搭桥、开路并到达终点
- Gold Schema：9 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION1–4 控制角色四向移动 | 角色按上、下、左、右移动；墙体或实体阻止位移。 |
| ACTION6 点击同组机关切换世界状态 | 同字母/同组的桥、门或平台切换可见性、碰撞性或形态。 |
| 起重机方向按钮沿吊臂网格移动抓取点 | 吊机锚点移动一格；携带物与锚点同步移动，碰撞时整次移动回退。 |
| 抓取按钮拾取或释放锚点处对象 | 空载时附着对象；有载时释放对象并保持当前位置。 |
| 桥段可被搬运并通过形态循环连接道路 | 桥段位置/朝向/版本改变后参与碰撞和支撑，能够填补角色路径。 |
| 角色取得钥匙会开启同标识阻挡 | 钥匙被移除，对应门/阻挡变为可通行。 |
| 角色失去支撑会消耗一次恢复并回到快照 | 若仍有恢复次数则恢复关卡快照；次数耗尽时 GAME_OVER。 |
| 角色到达目标位置时过关 | 进入下一关；最后一关满足时 WIN。 |
| 界面资源耗尽时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
