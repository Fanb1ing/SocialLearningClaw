# SP80 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：摆放容器并倾倒液体，让液体到达所有目标且避开危险区
- Gold Schema：7 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION6 点击容器/固体选择活动对象 | 命中对象成为当前活动对象。 |
| ACTION1–4 逐像素移动活动对象 | 对象向上、下、左、右移动一个像素；非法移动保持原位。 |
| ACTION5 开始一次液体倾倒模拟 | 生成液体粒子并逐帧在重力方向流动。 |
| 液体遇阻会沿侧向寻找可用路径并分流 | 粒子尝试两个侧向位置，可用时分支；之后继续受重力影响。 |
| 任意液体进入危险区域会判定本次失败 | 本次倾倒失败并恢复液体与可动物体初态。 |
| 所有接收目标被液体到达且无危险接触时过关 | 每个目标位置均有液体到达且没有危险命中时进入下一关。 |
| 失败倾倒有次数上限并受动作预算约束 | 超过允许倾倒次数或预算归零时 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
