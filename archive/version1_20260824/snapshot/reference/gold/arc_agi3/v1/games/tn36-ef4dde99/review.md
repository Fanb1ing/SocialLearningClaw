# TN36 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：编辑二进制程序并运行，使对象的位置、尺寸、旋转和颜色匹配目标
- Gold Schema：8 条
- 覆盖：7 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 点击程序位会切换比特并改变指令编号 | 该位在 0/1 间切换；同一指令格的位按二进制组合成命令编号。 |
| 程序选择器在多个独立程序间切换并保留内容 | 当前编辑区切换到对应程序；离开前的位模式被保存。 |
| 点击运行区按顺序执行当前程序 | 从第一条命令开始逐条执行，等待每条动画和碰撞结算后继续。 |
| 移动命令按编号产生一格或两格位移 | 活动对象沿指定方向移动；墙体或对象碰撞可阻止或破坏移动。 |
| 变换命令旋转、缩放或改色 | 对象按命令旋转 90/180/270°、增减尺寸，或切换到指定颜色。 |
| 命令后的边界和碰撞决定是否保留变换 | 非法结果被阻止；特定可破坏对象按碰撞规则移除。 |
| 对象四个属性完全匹配目标时过关 | 位置、尺寸、旋转和颜色全部与目标一致时进入下一关。 |
| 背景周期左移形成点击时限 | 场景向左滚动；关键对象被边界吞没时 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
