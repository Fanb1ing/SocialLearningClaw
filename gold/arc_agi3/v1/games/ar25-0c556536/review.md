# AR25 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：移动实物及其镜像组合，使所有目标标记被组合图形覆盖
- Gold Schema：8 条
- 覆盖：8 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 实物与递归镜像共同构成有效图形 | 实物像素会沿相交镜轴递归反射；目标判定使用实物与全部有效镜像的并集。 |
| ACTION1–4 移动当前选中实物 | 选中实物向上、下、左、右移动一个单位，镜像随新位置重算；越界输入不移动。 |
| 镜面按自身轴向反射图形 | 镜像出现在到镜轴等距的另一侧；只支持单轴的对象不会继续产生另一轴镜像。 |
| 跨越镜面相对距离会自动旋转实物 | 实物自动旋转 90°并重新计算镜像，以保持镜面关系。 |
| ACTION6 点击或 ACTION5 循环切换活动对象 | 点击命中的实物/镜像所对应实物成为活动对象；ACTION5 按固定次序选择下一对象。 |
| ACTION7 恢复上一移动快照 | 恢复移动前的实物位置与朝向，并重算镜像。 |
| 全部目标标记被组合图形覆盖时过关 | 每一个目标标记位置都落在实物或其有效镜像像素上时进入下一关。 |
| 有效操作耗尽预算时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
