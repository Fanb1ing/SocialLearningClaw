# M0R0 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：用对称控制或单独控制让四类图形两两重合配对
- Gold Schema：8 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 全局 ACTION1–4 以四种镜像关系同时移动四组对象 | 一组同向移动，另三组分别水平镜像、垂直镜像、双轴镜像移动。 |
| ACTION6 选择对象后只移动该对象 | 进入单独控制模式；随后方向输入只移动该对象。点击空处返回全局模式。 |
| ACTION5 不改变棋盘但仍计入操作次数 | 对象位置、配对和门状态均保持不变；全局 action 计数照常增加。 |
| 两个对象同坐标会配对并退出后续控制 | 两者合并为配对态，不再碰撞也不再参与移动。 |
| 三个以上对象同时相撞只接受首个合法配对 | 仅首对完成合并，其余对象回到移动前位置。 |
| 剩余对象压住传感器时对应门暂时移除 | 对应阻挡门变为不可碰撞；离开传感器后门恢复。 |
| 所有对象均完成两两配对时过关 | 不再有可触碰的未配对对象时进入下一关。 |
| 累计操作超过上限时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
