# VC33 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：点击隔板转移空间或交换两侧内容，使彩色物体到达匹配通道
- Gold Schema：7 条
- 覆盖：7 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 关卡重力轴决定所有前后、上下和宽高计算 | 同一机制沿重力轴执行；正负方向决定靠近/远离端的比较。 |
| 点击可调隔板会从一侧削去单位并加到另一侧 | 隔板两侧空间按重力方向一增一减，受支撑物体随边界移动。 |
| 物体随其支撑面和可用空间重新落位 | 位于受影响支撑上的对象沿重力方向同步移动，且不会越过最近墙面。 |
| 点击夹在两个合法空间之间的交换器互换两侧对象 | 交换器先移开，再把两侧受支撑对象移动到对侧，最后回到原位。 |
| 缺少任一侧完整支撑时不能交换 | 交换动作不启动。 |
| 每个彩色源必须与同色目标通道连通 | 对每个彩色源，都存在含该颜色的目标对象位于同一重力横截面且与其支撑墙连通，才进入下一关。 |
| 有效点击耗尽步数时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
