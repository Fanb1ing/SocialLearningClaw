# CN04 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：移动和旋转彩色图形，使所有标记像素按同色两两重合
- Gold Schema：7 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 两种标记颜色分别形成独立配对集合 | 只有相同标记颜色之间的重合才算该颜色的有效配对。 |
| ACTION6 点击图形选择或循环重叠图形 | 单个命中时选中它；同一像素有多个图形时按点击次序循环选择。 |
| ACTION1–4 移动选中图形 | 图形向上、下、左、右移动一格；越界时保持原位。 |
| ACTION5 旋转单个活动图形 | 活动图形绕自身旋转 90°。 |
| ACTION5 在重叠候选间循环 | 改选下一个重叠图形而不旋转。 |
| 同色标记重合后在显示上被消去 | 对应标记视为已配对并显示为消除态；分离后恢复未配对态。 |
| 全部标记像素完成同色配对时过关 | 所有颜色 8/13 的原始标记都有另一图形的同色标记与其重合时进入下一关。 |

## 审核重点
