# SB26 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：重排嵌套序列节点，使递归求值结果与输出序列一致
- Gold Schema：7 条
- 覆盖：8 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 外框表示有序序列，特殊节点引用另一外框 | 框内项目从左到右求值；引用节点按自身颜色/标识进入对应子框，形成递归序列。 |
| ACTION6 先选节点，再点击节点或空位完成交换/移动 | 首次点击选中；再次点击另一节点交换位置，点击合法空位把选中节点移入该位。 |
| 输出区与上方参考节点不可直接编辑 | 不会进入选中或交换流程。 |
| ACTION5 从入口框递归展开序列 | 求值器按框内顺序前进；遇到引用时进入子框，子框结束后返回父框下一项。 |
| 展开叶颜色必须逐项匹配输出槽 | 叶颜色等于当前输出槽颜色则继续；不相等或出现非法递归则本次求值失败。 |
| 递归展开完整且恰好匹配全部输出时过关 | 所有输出槽均被按序匹配且没有多余值时进入下一关。 |
| ACTION7 撤销编辑；编辑和求值消耗能量 | 撤销恢复上一布局；能量降到零且未完成时 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
