# SU15 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：点击产生收缩圆形脉冲，移动和合并对象以满足目标区计数
- Gold Schema：8 条
- 覆盖：9 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION6 点击场内位置产生收缩圆形脉冲 | 以点击点为圆心显示半径逐步缩小的环，并选中初始半径内的对象。 |
| 脉冲使圈内对象沿相对圆心方向移动 | 对象在若干帧内沿径向移动；不同对象类别可向内/向外并具有不同速度。 |
| 相同等级对象碰撞会合并升级 | 它们被替换为位于平均中心的下一等级对象；最高等级再合并则消失。 |
| 不同等级对象相撞会触发冲突而不升级 | 进入冲突/受击处理，不按同级合并规则生成升级对象。 |
| 未被脉冲直接操纵的敌对对象会追向最近主对象 | 敌对对象按其类别速度接近最近目标；接触会降低目标等级或移除目标。 |
| 目标区按对象等级或敌对类别精确计数 | 每项要求的类型/等级数量必须与关卡数据完全相等，多一个或少一个都不满足。 |
| 目标区内精确计数全部满足时过关 | 所有关卡定义的类型计数均准确满足时进入下一关。 |
| ACTION7 恢复上一次脉冲前快照 | 重建主对象和敌对对象的类型、等级与位置。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
