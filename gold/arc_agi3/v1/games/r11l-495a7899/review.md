# R11L Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：拖动组成图形并放到颜色集合匹配的目标上
- Gold Schema：8 条
- 覆盖：6 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| ACTION6 点击部件将其选中 | 部件高亮并成为后续落点点击的移动对象。 |
| 选中后点击空位置把部件中心移动到点击点 | 部件移动到目标位置；与其关联的组合中心按所有子部件中心重新定位。 |
| 固定阻挡禁止放置 | 移动不开始，部件保持原位。 |
| 组合容器吸收接触的小彩色片段 | 片段颜色像素写入组合图形，片段从棋盘移除。 |
| 组合图形与目标按非零颜色集合匹配 | 只有两者出现的非零颜色集合完全相等才算该目标满足。 |
| 组合图形接触危险区会回退并累计失败 | 移动动画倒放到起点；累计五次后 GAME_OVER。 |
| 所有规定目标保持匹配一段确认时间后过关 | 全部目标完成确认动画后进入下一关。 |
| 60 次点击预算耗尽时失败 | 游戏进入 GAME_OVER。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
