# RE86 Gold Schema v1 — 人工审核稿

> 状态：待人工审核。语义来自固定源码；运行证据为全关卡加载与可用 action 烟雾检查，不替代逐条语义审阅。

## 摘要

- 核心任务：移动并借助边界改变多个轮廓，使合成像素匹配目标模板
- Gold Schema：7 条
- 覆盖：8 个 levels；每条机制和每关目标均已映射

## 规则

| 机制 | 结论 |
|---|---|
| 带中心标记的轮廓是当前活动图形 | 只有活动轮廓响应方向输入；活动标记随选择更新。 |
| ACTION1–4 移动活动轮廓 | 轮廓向上、下、左、右移动固定像素距离。 |
| ACTION5 循环选择下一个轮廓 | 当前标记清除，下一个轮廓获得活动标记。 |
| 轮廓撞到特定边界会改变尺寸或内部标记 | 矩形轮廓按接触方向增减宽高；其他轮廓移动其中心结构，随后重新计算活动标记。 |
| 目标比较使用全部轮廓像素的叠加 | 全部可见非透明像素合成为一个候选图案，不要求单个轮廓独立匹配。 |
| 目标颜色 4 是通配符，透明像素不比较 | 颜色 4 接受任意候选颜色；目标透明位置不施加约束，其余位置必须相等。 |
| 合成图案满足全部目标像素时过关 | 所有非透明、非通配目标像素与合成图案一致时进入下一关。 |

## 审核重点

- 是否有规则抽象过粗或应当拆分；
- 是否存在只属于某一关初始配置、不应作为通用 Schema 的内容；
- 对混淆对象的中文命名是否需要改得更中性。
